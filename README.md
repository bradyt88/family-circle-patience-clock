# Patience Clock

A standalone, free-to-play web version of the classic 52-card Clock Patience game.

## Current features
- 52-card deck, randomly shuffled for each standard game.
- 12 clock piles, with four cards dealt to each pile.
- Four-card centre DRAW pile.
- Separate KINGS collection pile.
- Animated four-round deal, starting at 1 o'clock and moving clockwise.
- Revealed cards appear in the inner clock area and do not replace their original pile.
- A = 1, 2–10 = matching hour, J = 11, Q = 12.
- Kings go to KINGS; the next card comes from DRAW.
- The fourth King ends the game immediately unless it is the 52nd/final card, which is a win.
- Click/tap the highlighted source pile to reveal a card, then drag it to its correct destination.
- Landscape-first responsive layout for phones, tablets and desktop.
- Daily Clock mode with a deterministic daily arrangement.
- Personal records stored locally on the device.
- No accounts, adverts or backend dependency in the current build.
